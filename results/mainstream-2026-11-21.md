# Haswell and RX 580 upstream review · 2026-11-21

KoboldCpp `concedo_experimental` advanced by 200 commits from `ed246f446` to `eccf1a425d9e68be0dc0e291339c95ca132c0426`. It includes [SD model detection and interleaved prompts](https://github.com/LostRuins/koboldcpp/pull/2648), [atomic save-data writes](https://github.com/LostRuins/koboldcpp/pull/2659), [text generation disconnect handling](https://github.com/LostRuins/koboldcpp/pull/2658) and the [TTS build fix](https://github.com/LostRuins/koboldcpp/pull/2660). The local patch replay retains upstream indexed KV removal for specific sequences and the existing bounded path for removal across sequences. The RMSNorm, SCALE and SiTU ports follow the upstream typed Vulkan dispatch.

| Area | Decision |
| --- | --- |
| Haswell Q8_0 | Apply the signed-byte widening path in groups of eight. The standard F16 scale and F32 multiplication are reused. The second 4,096-element comparison went from 0.537 to 0.449 µs, 16.4% lower median time. All 65,542 test cases matched the release control byte for byte in every trial. With the final recipe, the median went from 0.706 to 0.553 µs. [Operator data](haswell-q8-0-decode-20261121.json) |
| RX 580 | The upstream [Stream-K path](https://github.com/ggml-org/llama.cpp/pull/28528) selects cooperative matrices v2. [Mixed-signedness MMQ](https://github.com/ggml-org/llama.cpp/pull/31045) selects hardware integer dot products. The tested Polaris has a wave64 scalar path and lacks those capabilities. The [real ABDM comparison](rx580-abdm-20261119.json) supports retaining the scalar kernels and its timings remain tied to the earlier EXE. |
| llama.cpp candidates | [Chunked Vulkan Gated Delta Net](https://github.com/ggml-org/llama.cpp/pull/30207) needs cooperative matrix features. [RMSNorm/RoPE loop control](https://github.com/ggml-org/llama.cpp/pull/31149) reports Windows RTX 5070 Ti measurements. [Reduced CPU threadpool polling](https://github.com/ggml-org/llama.cpp/pull/32378) focuses on CPU time and power in multi-backend runs. Its source reports a slowdown on a small model in one environment. |
| Audio.cpp | [Blocked CPU Mamba-1 and quantized-V attention](https://github.com/0xShug0/audio.cpp/pull/1342) report Zen 5 measurements. The attention change groups exponent and scale updates in a different reduction order, and the selectable GELU approximation changes numerical output. The [Kokoro workspace port](https://github.com/0xShug0/audio.cpp/pull/1355) targets that embedding/voice pipeline. |
| Diffusion and other forks | The [SD server TTL proposal](https://github.com/leejet/stable-diffusion.cpp/pull/2385) targets idle model eviction. The portable supervisor already loads alternate models on demand and keeps the photo profile resident. The [ik_llama.cpp Nemotron-H change](https://github.com/ikawrakow/ik_llama.cpp/pull/2949) is model-specific. New [JQ quant formats](https://github.com/ggml-org/llama.cpp/pull/30718) require separately qualified weights. |

The measured `ggml-quants.c` translation unit is identical in upstream `ee5ff66b` and `eccf1a42` before the local ports. The Haswell timings are from a CPU row conversion benchmark. Full model generation can spend a different fraction of its time in this operator. The installed models and profiles use their current settings.

MinGW uses escaped byte strings for the shader arrays and compiles the shader object separately. The aggregate manifest for all 1599 SPIR-V modules (41956628 bytes) matched across the packaging change. The manifest SHA-256 is `b81e428304c7dfc9fefa271134dca1077be83d7da0acba070891e091b004c71a`.
