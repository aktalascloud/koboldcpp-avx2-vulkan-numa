# KoboldCpp upstream · 2026-11-26

The official `concedo_experimental` branch advanced by 158 commits from `5b0cbafd` to `1dfd0825`. The update includes [SD generation state fixes](https://github.com/LostRuins/koboldcpp/pull/2661), the music autoswap changes, [audio FFT updates](https://github.com/ggml-org/llama.cpp/pull/32815), [BPE tokenization changes](https://github.com/ggml-org/llama.cpp/pull/32859), [CPU matmul locality](https://github.com/ggml-org/llama.cpp/pull/30846) and [template handling for EOS](https://github.com/LostRuins/koboldcpp/pull/2665) and [text parts](https://github.com/LostRuins/koboldcpp/pull/2678).

- The MOSS FFN path uses the upstream [strided Vulkan SCALE implementation](https://github.com/ggml-org/llama.cpp/pull/32735). The flat fused path retains the contiguous-input guard. The Polaris `vec4` dispatch requires contiguous input and output, with the existing shape and alignment constraints.
- The upstream [typed RPC request parser](https://github.com/ggml-org/llama.cpp/pull/32651) builds graphs iteratively, so that local port is now redundant. The local transfer port retains the buffer-range check for empty tensors. The ordered patch series reproduces the exact patched source with 76 diffs.
- The two SenseNova code ports still apply after adapting the upstream op table and quantization metadata. They preserve the upstream operation numbers and pin F32 router and convolution tensors for SenseNova quantization. The weight set and launch profiles are retired.
- The experimental branch has 7 open PRs, and `concedo` has 4. SD [#2663](https://github.com/LostRuins/koboldcpp/pull/2663) and [#2679](https://github.com/LostRuins/koboldcpp/pull/2679) refactor the live media adapter and its ABI. [#2434](https://github.com/LostRuins/koboldcpp/pull/2434) overlaps the current grammar index-cache implementation. [#2674](https://github.com/LostRuins/koboldcpp/pull/2674) targets macOS mmap prefetch. [#2547](https://github.com/LostRuins/koboldcpp/pull/2547) adds an alternative sampler. These open PRs were reviewed and left out of this build.
- The official [Vulkan GDN replay changes](https://github.com/ggml-org/llama.cpp/pull/32721) have cooperative-matrix paths outside the RX 580's capabilities. The newer [SD Hunyuan VAE padding change](https://github.com/leejet/stable-diffusion.cpp/pull/2374) targets Hunyuan workloads. [audio.cpp Windows runtime dispatch](https://github.com/0xShug0/audio.cpp/pull/1367) solves baseline portable packaging, while this fork builds the shared engine for Haswell directly. The standalone engine heads were reviewed separately and the release uses the bundled upstream engine revisions.

Validation scope covers compilation, source identity, installed binary hashes, cold startup, visible window and read-only API checks. Generation and throughput were outside this maintenance pass.
