# KoboldCpp upstream review · 2026-11-28

The official experimental branch advanced by 107 commits from 1dfd0825 to 5db3674f. The bundled engine update includes direct recurrent-state reads, asynchronous graph input copies, BF16 input support for CPU matrix multiplication, and MoE cache selections across backends. [Upstream compare](https://github.com/LostRuins/koboldcpp/compare/1dfd0825...5db3674f) · [Recurrent state](https://github.com/ggml-org/llama.cpp/pull/30139) · [Input copies](https://github.com/ggml-org/llama.cpp/pull/30685) · [BF16 inputs](https://github.com/ggml-org/llama.cpp/pull/32533) · [MoE cache](https://github.com/ggml-org/llama.cpp/pull/33133).

- Vulkan gains compact indexed bias in FlashAttention for Inkling 2 Mini and more precise AMD architecture and subgroup checks on Windows. These changes do not establish a generic RX 580 speed gain. [Compact bias](https://github.com/ggml-org/llama.cpp/pull/32898) · [AMD architecture classification](https://github.com/ggml-org/llama.cpp/pull/33123).
- The merged SD adapter refactor moves video arguments into a typed parameter structure. Local JPEG quality and Wan latent export follow those fields, including the actual video dimensions and seed. The native upscaler runs only when requested. [SD refactor](https://github.com/LostRuins/koboldcpp/pull/2663) · [Upscaler guard](https://github.com/LostRuins/koboldcpp/commit/4f2672b59).
- Ollama chat now applies request options and structured output. Model inspection reports tools and vision capabilities. [Chat options](https://github.com/LostRuins/koboldcpp/pull/2682) · [Structured output](https://github.com/LostRuins/koboldcpp/pull/2683) · [Model capabilities](https://github.com/LostRuins/koboldcpp/pull/2684).
- Reviewed nine open PRs, six on experimental and three on concedo. Kept the current media ABI because the follow-on SD refactor is still open. Layer looping and two-model stitching introduce separate model semantics. Mmap prefetch control, cache persistence, Linux ISA packaging, alternative sampling, the index-based grammar cache overlap, and VLM video input were also reviewed. [Open PRs](https://github.com/LostRuins/koboldcpp/pulls) · [SD API refactor](https://github.com/LostRuins/koboldcpp/pull/2679).
- The standalone llama.cpp head 8e23278c has a follow-up for empty Vulkan CONV_3D kernels and cooperative-matrix GDN work. The first is a narrow edge case and the second requires hardware support beyond Polaris. SD head 3b0426f7 accounts for idle backend buffers in a new cross-layer memory budget. That change depends on a newer GGML interface and requires testing across graph cuts and weight prefetch. Audio head 604904ad has TTS changes and an MSVC-specific CPU spinning fix. The MinGW build already uses the x86 pause path. ik_llama.cpp head c9643aeb includes an independent SenseNova DFlash port. This build retains the local model code and the retired weights stay absent. [CONV_3D](https://github.com/ggml-org/llama.cpp/pull/33106) · [GDN](https://github.com/ggml-org/llama.cpp/pull/32860) · [SD VRAM budget](https://github.com/leejet/stable-diffusion.cpp/pull/2446) · [MSVC spin loop](https://github.com/0xShug0/audio.cpp/pull/1407) · [ik_llama DFlash](https://github.com/ikawrakow/ik_llama.cpp/pull/3009).
- The andrewdhannah and advanced-lvl-up Polaris fork tips are unchanged. RDNA Boosts updates prompt admission in llama-server, and infr changes its Rust Vulkan adapter and test device selection. [Polaris fork](https://github.com/andrewdhannah/vulkan-polaris-llama/commit/e29790e07) · [gfx803 fork](https://github.com/advanced-lvl-up/Rx470-Vega10-Rx580-gfx803-gfx900-fix-AMD-GPU/commit/6547664db) · [RDNA Boosts](https://github.com/stew675/llama-cpp-rdna-boosts/commit/706ff169e) · [infr](https://github.com/KessokuNet/infr/commit/cb7004816).
