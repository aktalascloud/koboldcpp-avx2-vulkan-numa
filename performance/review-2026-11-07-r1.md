## Selected ports

- **AVX2 GELU and GEGLU.** Vectorize lookups into the existing FP16 table with F16C conversions. Preserve the scalar path for NaN payloads and mask the gate on saturated negative inputs before multiplying. The output bytes matched in 52 checks. [PR 30232](https://github.com/ggml-org/llama.cpp/pull/30232)
- **Vulkan RMSNorm.** Apply the long-row idea to the existing Y/Z-strided shader. Add a separate X-strided plain and weighted pipeline, selected only when the device's X limit is exceeded. Large shapes use the ordinary decomposed graph for unsupported fusions. This RX 580 driver exposes a physical X limit of 4,294,967,295, so a limit of 65,535 was set only inside the isolated check. All 12 shapes matched both the unrestricted computation and the split reference bit for bit. Ordinary preprocessed shaders match after accounting for independent declaration order. The report retains both sets of SPIR-V hashes. [Audio PR 1120](https://github.com/0xShug0/audio.cpp/pull/1120) · [RX 580 report](https://github.com/0xShug0/audio.cpp/issues/1114)
- **GGML allocation views.** Keep a view-only tail in the parent allocation when the parent alone exceeds the nominal chunk maximum. Exercise the actual buffer planner with both a terminal view and a subsequent tensor. [PR 25584](https://github.com/ggml-org/llama.cpp/pull/25584)
